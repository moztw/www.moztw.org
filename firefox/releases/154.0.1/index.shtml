Firefox 新鮮事

  • 修正

    修正近期密碼儲存機制變更導致存取已儲存密碼變慢，以及非預期出現主要密碼提示的問題。（Bug 2064411、Bug 2065593、Bug 2063993）

  • 修正

    修正部分網站無法自動填寫地址的問題。（Bug 2065145、Bug 2063599）

  • 修正

    修正 Windows 上 Firefox 每次啟動都新增一個開始功能表捷徑的問題。（Bug 2064652）

  • 修正

    修正部分透過 HTTP 載入的網站，連線至區域網路裝置時未顯示權限提示就連線失敗的問題。（Bug 2059274）

  • 修正

    修正開啟設有區域網路共用檔案連結的內部網路網站時，可能發生當機的問題。（Bug 2064648）

  • 修正

    修正 Windows 系統字型為 MS UI Gothic 時，分頁標題開頭遭到截斷的問題。（Bug 2056856）

已知問題

  • 尚待修復

    啟用垂直分頁的使用者重新啟動 Firefox 後，側邊欄可能不再顯示。重新啟動後可點擊工具列上的側邊欄按鈕，重新啟用垂直分頁。已於 Firefox 155.0.1 修復。

  • 尚待修復

    在全螢幕模式下隱藏工具列時（Windows 與 Linux 的預設行為），將游標移到螢幕左側邊緣不會顯示垂直分頁側邊欄。暫時可將游標移至螢幕頂端，同時顯示工具列與側邊欄；也可以在工具列上按右鍵，取消勾選「隱藏工具列」。我們正在修正此問題。（Bug 2064638）

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
