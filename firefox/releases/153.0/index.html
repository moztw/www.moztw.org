Firefox 新鮮事

  • 全新功能

    Windows 現已支援高動態範圍（HDR）影片播放；需在 Windows「設定」→「系統」中啟用目標顯示器的 HDR 模式。目前不支援僅提供「HDR 影片串流」的筆記型電腦螢幕；部分手機以特定方位錄製的影片目前也不會以 HDR 顯示。

  • 全新功能

    容器可讓你在同一個瀏覽器視窗中，依工作、購物、個人、銀行等線上生活的不同面向，分開登入不同帳號，把 Cookie 與廣告追蹤隔離在各自的容器內。

  • 全新功能

    可用二維條碼（QR Code）分享任何已開啟的頁面。對分頁按右鍵，選擇「分享」→「產生 QR Code」。海報、邀請函、橫幅與其他印刷品上用起來超棒。

  • 全新功能

    現在可將 PDF 拖曳到 PDF 側邊欄以合併多個 PDF。

  • 全新功能

    現在可使用 Firefox PDF 編輯器，新增圖片成為 PDF 內的新頁面。

  • 全新功能

    在網址列輸入「pick color」、「color picker」或「eyedropper」，並選擇「挑選色彩」快速動作，即可快速在任何頁面上挑選並複製顏色。

  • 全新功能

    新增支援 Apple 系統層級的全螢幕熱鍵（Globe-F）。

  • 全新功能

    Firefox 現在依 eIDAS 規範驗證並顯示合格網站身分驗證憑證（QWACs）。

  • 全新功能

    改善對含疊加層（overlays）影片的支援，讓使用者更容易從右鍵選單存取影片操作。

  • 全新功能

    當網站可存取你的位置時，Firefox 現在會以紅色醒目顯示位置權限圖示。搜尋結果頁上先前隱藏的權限圖示現在也會顯示。

  • 全新功能

    智慧視窗：

    • 可直接在智慧視窗助手查看並選擇 AI 模型。
    • 新分頁現在包含熟悉的網址列，可輸入網址與搜尋網路。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 實驗中

    現在可在網址列輸入「labs」或「experiment」，並選擇「開啟 Firefox 實驗室」快速動作，快速開啟 Firefox 實驗室。

  • 實驗中

    Firefox Labs 現在提供實驗性的 JPEG XL 圖片格式支援，通常比 WebP、JPEG、PNG、GIF 有更好的壓縮，並設計來取代這些格式。可在設定的 Firefox 實驗室面板啟用。

  • 修正

    多項安全性修正。

  • 變更

    擴充套件預設不再可存取本機檔案。使用者可透過新的「Access local files on your computer」權限授予或撤銷，與「Access your data for all websites」分開。

  • 變更

    現在預設對所有使用者啟用區域網路存取限制。網站若要連線到你區域網路上的裝置，或你裝置上的應用程式與服務，Firefox 會先要求網站取得權限。

  • 變更

    已從設定介面移除過時的 Cookie 設定。仍使用該模式的使用者應切換為預設的「隔離跨站 Cookie」行為。更多資訊

  • 企業版

    你可以在 Firefox 153 企業版版本資訊 中找到政策更新與企業版相關的錯誤修復資訊。

  • 開發功能

    Firefox 153 開發者資訊

  • 開發功能

    選項面板新增「Local Mode」設定，讓開發者可透過自訂來源載入本機目錄。這可簡化對無法在標準 file:// URL 上運作之 API 的測試，不必再跑本機網頁伺服器，並支援多組目錄對應。

  • 網路平台

    Firefox 現在支援非標準 ::-webkit-scrollbar 虛擬元素的有限子集，以改善網頁相容性：

    • 含非零 width/height 的規則會為受影響容器停用 overlay 捲軸。
    • 在 ::-webkit-scrollbar 上使用 display: none 的行為如同 scrollbar-width: none，會隱藏捲軸。
    • @supports selector(::-webkit-scrollbar) 現在會評估為 true。
    • 刻意不支援完整的樣式設定功能（顏色、border-radius 等）。
  • 網路平台

    vertical-align 屬性在 Firefox 149 已成為 baseline-source、alignment-baseline 與 baseline-shift 的簡寫屬性。現在 alignment-baseline 支援新關鍵字 alphabetic、ideographic、central、mathematical、hanging，擴充可用於對齊的基線種類。

  • 網路平台

    實作新的 popover=hint 規格，移除一系列不一致且非預期的行為。

  • 網路平台

    circle() 與 ellipse() 函式接受兩個新關鍵字 closest-corner 與 farthest-corner，用於徑向尺寸。

  • 網路平台

    新增的 Error.stackTraceLimit 屬性可設定擷取 JavaScript 錯誤堆疊的最大深度，作為效能優化。

  • 網路平台

    開發者現在可使用 text 匯入屬性，透過模組系統匯入文字檔。

  • 網路平台

    Picture-in-Picture API 讓網頁開發者可使用瀏覽器的子母畫面功能。

  • 網路平台

    Intl.LocaleInfo 提案新增查詢語系資訊的能力，例如週資料（一週的第一天、週末起訖日）、文字方向與該語系使用的小時週期。

  • 網路平台

    MediaCapabilities.decodingInfo() 與 MediaCapabilities.encodingInfo() 方法現在接受 "webrtc" 組態類型，讓網站可查詢特定音訊或視訊組態是否可在 WebRTC 中解碼或編碼，以及是否流暢與／或省電。

  • 網路平台

    HTTP Compression Dictionaries 在 153 以逐步釋出方式啟用，將在未來版本永久啟用。對有使用的網站可大幅減少網路流量大小。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

已知問題

  • 尚待修復

    部分 Windows 使用者在更新後啟動 Firefox 時可能發生當機，原因是不完整的更新導致 Firefox 安裝處於不一致的狀態。（Bug 1681745）若受到影響，可從 firefox.com 下載 Firefox，並覆蓋安裝到現有的 Firefox 上即可修復。你的書籤、密碼與其他資料會另外儲存，不會受到影響。已於 Firefox 153.0.1 修復。

下載與安裝

系統需求

在安裝 Firefox 前請先確定您的電腦是否合乎系統需求。

下載 Firefox

您可以由此下載最新的 Firefox，或取得 Windows、Linux 及 Mac OS X 平台上的各國語言版本，或由此下載 Firefox 未來發行版本（測試版）。若需自行編譯其他平台或語言的版本，請見本文件最末節。

安裝 Firefox

請注意：安裝新版 Firefox 將覆蓋現存的 Firefox 程式，您不會遺失書籤或瀏覽記錄，但有些附加元件可能要更新才能繼續使用。詳細安裝步驟請參見如何安裝與更新 Firefox。

移除 Firefox

在 Windows 作業系統中，您可以使用「新增或移除程式」移除 Firefox。macOS 的使用者請將 Firefox 程式移至垃圾筒；Linux 使用者則請移除包含 Firefox 的資料夾。

一般狀況下，移除 Firefox 時不會把書籤、瀏覽記錄、擴充套件和其他附加元件一併刪除，這些資料會保留在您的「個人設定資料夾」內，此資料夾可以在「說明」選單的「更多疑難排解資訊」找到，按下「應用程式一般資訊」中「設定檔目錄」旁的按鈕便可開啟它。

請留意，若您沒有手動刪除個人設定資料夾，移除後重新安裝 Firefox 將繼續沿用原本的設定檔。

附加元件及佈景主題

您可以由「附加元件管理員」或附加元件網站取得附加元件及佈景主題。 當 Firefox 升級時，附加元件可能因不相容於新版 Firefox 而被停用，此時則需要原作者進行升級。

疑難排解

  • 設計不良或不相容的套件將導致瀏覽器發生問題，包含當機或網頁瀏覽速度變慢等等狀況。如果您碰上瀏覽器無法開啟、視窗顯示不正常等等狀況，便可能是擴充套件或佈景主題的問題。這時請參考「Firefox 輔助說明：安全模式」一文開啟 Firefox 安全模式。在安全模式下，所有附加元件及佈景主題將被停用。請您在安全模式下移除有問題的擴充套件或佈景主題，再正常地啟動瀏覽器。
  • 如果您遇到與書籤、下載、視窗位置、工具列、瀏覽記錄或其他奇怪問題，建議您在回報問題前先建立新的使用者設定檔試試。請參考「Firefox 輔助說明：使用設定檔管理員建立或移除 Firefox 設定檔」一文建立新的使用者設定檔，並將各種設定（書籤、儲存的密碼等）從舊的設定檔中分次轉移到新的設定檔（可透過 Firefox Sync 同步功能進行）。

常見問題集

  1. 我該怎麼幫忙呢？

    我們需要開發員和測試社群回饋建議，幫我們將 Firefox 變得更盡善盡美。請先查閱 Firefox 輔助說明看看有沒有相關解答，再到 Bugzilla 回報你發現的錯誤；您也可以使用意見回饋功能表達意見。

  2. 我如何預覽未來的 Firefox 版本？

    加入 Aurora 或 Beta 開發頻道就可以搶先試用 Firefox 開發中版本。

  3. 我該到哪裡才能用中文問問題跟表示意見？

    請使用 Firefox 討論區，MozTW 社群團隊與熱心的 Firefox 用戶會定期閱讀上面的文章。

  4. 我該去哪裡取得新的佈景主題與擴充功能 (附加元件)？

    請到 Mozilla 附加元件中心下載 Firefox 的擴充套件及佈景主題。

  5. Firefox 是哪些人做出來的？

    Firefox 是由世界各地的 Mozilla 社群成員與員工合力開發。這裡有份長長的名單，列出部分曾對 Firefox 有重要貢獻的人。想要加入我們的大家庭嗎？或者加入 Mozilla 台灣社群？

  6. Firefox 的原始碼在何處？

    請參照 Getting Mozilla Source Code Using Mercurial 一文取得 Firefox 原始碼；如需編譯 Firefox，請參考 Build Instructions。

  7. 電子郵件程式呢？

    Firefox 能與您預設的任何郵件程式協同運作，而我們推薦您試試我們下一代的郵件軟體：與 Firefox 合作無間的 Mozilla Thunderbird。
