Firefox 新鮮事

  • 全新功能

    Windows 現已支援高動態範圍（HDR）影片播放；需在 Windows「設定」→「系統」→「顯示器」啟用 HDR 模式。目前不支援僅提供「HDR 影片串流」的筆記型電腦螢幕；部分以特定方向在手機錄製的影片目前也不會以 HDR 顯示。

  • 全新功能

    容器可讓你在同一個瀏覽器視窗中，將工作、購物、個人、銀行等線上生活分開登入不同帳號，同時把 Cookie 與廣告追蹤隔離在各容器內。

  • 全新功能

    可用 QR code 分享任何已開啟的頁面。對分頁按右鍵，選擇「分享」→「產生 QR Code」。適合海報、邀請函、橫幅與其他印刷品。

  • 全新功能

    現在可將 PDF 拖曳到 PDF 側邊欄，直接合併多個 PDF。

  • 全新功能

    現在可使用 Firefox PDF 編輯器，將圖片新增為 PDF 中的新頁面。

  • 全新功能

    在網址列輸入「pick color」、「color picker」或「eyedropper」，並選擇「Pick a color」快速動作，即可快速從任何頁面挑選並複製顏色。

  • 全新功能

    新增支援 Apple 系統層級全螢幕鍵盤指令（Globe-F）。

  • 全新功能

    Firefox 現在依 eIDAS 規範驗證並顯示合格網站驗證憑證（QWACs）。

  • 全新功能

    改善對含疊加層影片的支援，讓使用者更容易從右鍵選單存取影片操作。

  • 全新功能

    當網站取得你的位置權限時，Firefox 現在會以紅色醒目顯示位置權限圖示。搜尋結果頁上先前隱藏的權限圖示現在也會顯示。

  • 全新功能

    Smart Window：

    • 可直接從 Smart Window 助手查看並選擇 AI 模型。
    • 新分頁現在包含熟悉的網址列，可輸入網站與搜尋網路。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 全新功能

    現在可在網址列輸入「labs」或「experiment」，並選擇「Open Firefox Labs」快速動作，快速開啟 Firefox Labs。

  • 全新功能

    Firefox Labs 現在提供實驗性的 JPEG XL 圖片格式支援，通常比 WebP、JPEG、PNG、GIF 有更好的壓縮，並設計為可取代這些格式。可在設定的 Firefox Labs 面板啟用。

  • 修正

    多項安全性修正。

  • 變更

    擴充套件預設不再可存取本機檔案。使用者可透過新的「Access local files on your computer」權限授予或撤銷，與「Access your data for all websites」分開。

  • 變更

    區域網路存取限制現在預設對所有使用者啟用。Firefox 要求網站在連線到你區域網路上的裝置，或你裝置上的應用程式與服務之前必須請求權限。

  • 變更

    已從設定介面移除過時的 Cookie 設定。仍使用該模式的使用者應改為預設行為「Isolate cross-site cookies」。更多資訊

  • 企業版

    你可以在 Firefox 153 企業版版本資訊 中找到政策更新與企業版相關的錯誤修復資訊。

  • 開發功能

    Firefox 153 開發者資訊

  • 開發功能

    選項面板新增「Local Mode」設定，讓開發者可透過自訂來源載入本機目錄。這可簡化對無法在標準 file:// URL 上運作之 API 的測試，不必再跑本機網頁伺服器，並支援多組目錄對應。

  • 網路平台

    Firefox 現在支援非標準 ::-webkit-scrollbar 虛擬元素的有限子集，以改善網頁相容性：

    • 含非零 width/height 的規則會為受影響容器停用 overlay 捲軸。
    • 在 ::-webkit-scrollbar 上使用 display: none 的行為如同 scrollbar-width: none，會隱藏捲軸。
    • @supports selector(::-webkit-scrollbar) 現在會評估為 true。
    • 刻意不支援完整樣式能力（顏色、border-radius 等）。
  • 網路平台

    vertical-align 屬性在 Firefox 149 已轉換為 baseline-source、alignment-baseline 與 baseline-shift 的簡寫。現在 alignment-baseline 支援新關鍵字 alphabetic、ideographic、central、mathematical、hanging，擴充可用於對齊的基線種類。

  • 網路平台

    實作新的 popover=hint 規格，移除一系列不一致且非預期的行為。

  • 網路平台

    circle() 與 ellipse() 函式接受兩個新關鍵字 closest-corner 與 farthest-corner，用於徑向尺寸。

  • 網路平台

    新增的 Error.stackTraceLimit 屬性可設定擷取 JavaScript 錯誤堆疊的最大深度，作為效能優化。

  • 網路平台

    開發者現在可使用 text import attribute，透過模組系統匯入文字檔。

  • 網路平台

    Picture-in-Picture API 讓網頁開發者可使用使用者代理的子母畫面功能。

  • 網路平台

    Intl.LocaleInfo 提案新增查詢Locale 資訊的能力，例如週資料（一週的第一天、週末起訖日）、文字方向與該 Locale 使用的小時週期。

  • 網路平台

    MediaCapabilities.decodingInfo() 與 MediaCapabilities.encodingInfo() 方法現在接受 "webrtc" 組態類型，讓網站可查詢特定音訊或視訊組態是否可為 WebRTC 解碼或編碼，以及是否流暢與／或省電。

  • 網路平台

    HTTP Compression Dictionaries 在 153 以逐步釋出方式啟用，將在未來版本永久啟用。對有使用的網站可大幅減少網路流量大小。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
