Firefox 新鮮事

  • 全新功能

    macOS 的分享功能現在使用系統原生分享選擇器，除了 AirDrop、「訊息」與其他應用程式，也會顯示網頁預覽與最近聯絡人。你也可以一次分享多個選取的分頁。

  • 全新功能

    現在預設即可從側邊欄存取已儲存的密碼，不必先加入密碼工具。

  • 全新功能

    智慧視窗現在可監看網頁是否降價、補貨等變更。在對話中輸入 /watch 即可設定，Firefox 發現符合條件的變更時會傳送桌面通知。你可透過工具列上的工作按鈕，或 about:smartwindowtasks 頁面管理監看項目。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 修正

    修正上傳檔案對話框開啟的是上次儲存檔案的資料夾（例如「下載項目」），而非上次用於上傳的資料夾。

  • 修正

    修正 Zoom 網頁版等網站在最小化視窗中持續開啟時，記憶體使用量快速增加的問題。

  • 修正

    修正 Windows 上啟用 NVIDIA RTX Video HDR 時，部分影片顯示異常的問題。

  • 修正

    修正無法從已登入 Google 帳號的 Google Chrome 設定檔匯入書籤的問題。

  • 修正

    修正 macOS 上 Apple「書寫工具」的「取代」按鈕，在 Gmail 等部分網站插入剪貼簿內容，而非改寫後文字的問題。

  • 修正

    修正網頁中較長的下拉選單，有時在捲動前以空白取代最後幾個選項的問題。

  • 修正

    修正 Slack 等部分網站拒絕 HTTP/3 請求時，Firefox 未退回 HTTP/2 而導致網站無法載入的問題。

  • 修正

    修正 Linux 搭配 AMD 顯示卡時，在 ChatGPT 等網站檢視地圖或地點結果，導致 Firefox 使用過多記憶體的問題。

  • 修正

    修正 macOS 上的網頁遊戲有時漏掉快速按下遊戲控制器按鈕的操作。

  • 修正

    修正 Linux 使用 Wayland 時，點擊分頁有時使分頁脫離成為新視窗的問題。

  • 修正

    修正 Windows 與 Linux 上已關閉作業系統動畫效果時，選單與面板仍以淡入動畫顯示的問題。

  • 修正

    多項安全性修正。

  • 變更

    macOS 上，當 Firefox 為預設瀏覽器時，ChatGPT 等透過預設瀏覽器登入的應用程式，現在會在 Firefox 開啟登入頁面，而非 Safari。

  • 變更

    AI 聊天機器人的「摘要頁面」選項，現在會將網頁網址傳送給聊天機器人服務提供者，取代網頁文字，因此較長的頁面不再因內容遭截斷而只能產生部分摘要。

  • 變更

    現在可使用鍵盤快捷鍵搜尋已開啟的分頁：Windows 與 Linux 為 Ctrl+Shift+A，macOS 為 Cmd+Shift+A。「擴充套件與佈景主題」的快捷鍵則改為 Windows 與 Linux 的 Ctrl+Shift+F，以及 macOS 的 Cmd+Shift+E。這些快捷鍵可在 about:keyboard 中變更。

  • 變更

    以爪哇文、峇里文、加拿大原住民音節文字與西非書面文字（N’Ko）撰寫的網址，現在會以原文字顯示，不再顯示為以 xn-- 開頭的編碼文字。

  • 企業版

    Firefox 企業版的更新與修正，請參考 Firefox 企業版版本資訊；原則變更請參考 Firefox 管理文件變更紀錄。

  • 開發功能

    Firefox 159 開發者資訊

  • 開發功能

    網頁主控台現在允許重新宣告 let、const 與 class 變數，讓你編輯程式碼片段後重新執行，不會遇到重複宣告錯誤。

  • 網路平台

    Firefox 現在支援捲動驅動動畫，讓 CSS 動畫與 Web Animations API 動畫能隨容器的捲動位置，或元素捲入可見範圍時的可見程度推進。這項支援新增 animation-timeline、scroll-timeline、view-timeline 與 animation-range 屬性，以及 ScrollTimeline 與 ViewTimeline 介面。

  • 網路平台

    Firefox 現在支援限定作用範圍的自訂元素登錄表。透過 CustomElementRegistry() 建構子建立的登錄表，與全域的 window.customElements 登錄表互相獨立，讓使用相同標籤名稱的自訂元素能在同一頁面共存。

  • 網路平台

    相容裝置上的 WebGL 現在支援 EXT_clip_control 與 EXT_texture_mirror_clamp_to_edge 擴充功能，WebGL 2 則支援 EXT_texture_norm16。

  • 網路平台

    Sanitizer API 現在會在解析 HTML 的同時清理內容，而非解析完成後才清理，因此被清理器移除的元素不再執行自訂元素建構子。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
