Firefox 新鮮事

  • 全新功能

    現在可在智慧視窗中更快速地填寫表單。點擊表單欄位，或從來源中選擇「填入」時，智慧視窗會根據相關的已開啟分頁與已儲存的自動填寫資料，建議可填入的內容。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 全新功能

    將網頁儲存為 PDF，以及在 Linux 與 macOS 上列印時，Firefox 現在會產生無障礙支援更完善的 PDF。這也修正了數學符號缺漏等多項 PDF 顯示問題。

  • 全新功能

    Firefox 現在支援 JPEG XL 圖片格式，通常比 WebP、JPEG、PNG 與 GIF 具有更佳的壓縮率。

  • 全新功能

    新分頁現在會在「你的圖片」中保留多張自訂桌布，不再只保留最近使用的一張。

  • 全新功能

    Firefox 的翻譯功能現在支援下列語言：

    • 阿爾巴尼亞語
    • 白俄羅斯語
    • 菲律賓語
  • 修正

    修正 Ubuntu 預設佈景主題下，使用鍵盤選取網址列結果時，網站圖示（favicon）與反白底色混在一起的問題。

  • 修正

    修正 Firefox 載入網站圖示（favicon）時，可能發生當機的問題。

  • 修正

    修正 Windows 與 Linux 網址列的整合搜尋按鈕選單中，每個搜尋引擎名稱的首字母都加上底線，可能造成鍵盤快捷鍵衝突的問題。

  • 修正

    修正使用 Windows 高對比佈景主題時，「列出所有分頁」「設定」與「整合搜尋」等選單難以閱讀的問題。選單背景與文字現在會採用 Windows 設定中自訂對比佈景主題所選的「背景」與「文字」色彩。

  • 修正

    多項安全性修正。

  • 變更

    Firefox 不再將捲動位置四捨五入至整數螢幕像素，讓捲動更平順、更精確，尤其是在高解析度顯示器或頁面縮放時。

  • 企業版

    Firefox 企業版的更新與修正，請參考 Firefox 企業版版本資訊；原則變更請參考 Firefox 管理文件變更紀錄。

  • 開發功能

    Firefox 158 開發者資訊

  • 開發功能

    修正 WebSocket 訊息在連線建立後立即送達時，網路監控器可能漏掉這些訊息的問題。

  • 網路平台

    Firefox 現在支援 CSS calc() 中的帶型別算術運算，允許在數學函式內對單位進行乘除運算。

  • 網路平台

    Notification 建構子與 ServiceWorkerRegistration.showNotification() 現在支援 navigate 選項，可指定點擊通知後要前往的 URL。

  • 網路平台

    具有 autocomplete="webauthn" 屬性的輸入元素，現在也會顯示 WebAuthn 條件式介面。先前只有在該屬性包含另一個自動填寫欄位值時才會顯示，例如 autocomplete="username webauthn"。（深入瞭解）

  • 網路平台

    Firefox 現在支援 PerformanceResourceTiming.deliveryType 的 cache 值，讓網站能辨識由 HTTP 快取提供的資源。

  • 網路平台

    相容裝置現在可使用 WebGL 擴充功能 EXT_polygon_offset_clamp。

已知問題

  • 尚待修復

    透過第三方 PWAsForFirefox 工具啟動的網頁應用程式，可能無法在 Firefox 158 中啟動，並顯示「The installation seems to be incomplete.」（安裝似乎不完整）錯誤。將 PWAsForFirefox 更新至 2.20.1 或更新版本即可修復。若錯誤仍然出現，請在 PWAsForFirefox 擴充套件設定中，依序選擇「Reinstall runtime」（重新安裝執行環境）與「Patch profiles and runtime」（修補設定檔與執行環境）。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
