Firefox 新鮮事

  • 修正

    修正滑鼠游標移至網址列按鈕上時，NVDA 螢幕閱讀器未朗讀按鈕的問題。（Bug 2069276）

  • 修正

    修正連結內的元素在點擊時，未呈現 CSS :active 樣式的問題。（Bug 2067272）

  • 修正

    修正部分使用 CSS 錨點定位的網頁導致 Firefox 無回應的問題。（Bug 2070171）

  • 修正

    修正 macOS 27 上連按兩下標題列以還原 Firefox 視窗後，視窗立即再次最大化的問題。（Bug 2066632）

  • 修正

    修正 Windows 上內容處理程序啟動與結束時，Firefox 洩漏系統控制代碼的問題。（Bug 2069644）

  • 變更

    按下 Tab 鍵，焦點現在會直接移至網址列與搜尋列的文字欄位，不再先停留在搜尋引擎按鈕上。仍可使用 Shift+Tab 將焦點移至該按鈕。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
