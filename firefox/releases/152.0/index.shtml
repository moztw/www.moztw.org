Firefox 新鮮事

  • 全新功能

    Firefox 設定採用全新外觀：組織更精簡、分組更清楚、導覽更順暢，方便自訂。

  • 全新功能

    在隱私瀏覽視窗中，若追蹤器封鎖導致網站無法正常運作，現在可暫時為該分頁停用追蹤器封鎖。重新載入曾封鎖追蹤器的頁面時，Firefox 會顯示訊息，提供以較寬鬆保護重新載入的選項；其餘追蹤保護仍會維持啟用。

  • 全新功能

    現在可從網址列將瀏覽器靜音：輸入「mute」（或「shush」、「sssh」），並使用網址列快速動作，靜音所有 Firefox 視窗中目前正在播放聲音的分頁。

  • 全新功能

    改善 macOS 上較進階游標移動指令的支援，包含與段落邊界相關的指令。

  • 全新功能

    在 Windows 與 Linux 上，現在可透過分頁右鍵選單複製連結：對分頁按右鍵，選擇「分享」→「複製連結」，不必先切換到該分頁。選取多個分頁時，可一次複製所有選取的連結。Windows 使用者仍可從「分享」選單使用 Microsoft 分享選項。

  • 全新功能

    現在可透過「更多工具」→「自訂工具列」加入「傳送分頁」工具列按鈕。

  • 全新功能

    翻譯新增語言：巴斯克語、加利西亞語。

  • 全新功能

    克羅埃西亞語、英語（英國）、喬治亞語、波斯語、斯洛維尼亞語、塔吉克語、坦米爾語、藏語、土耳其語、威爾斯語與科薩語的 Firefox 組建，現在內建拼字檢查字典。

  • 全新功能

    Firefox Labs 現在提供實驗性的 JPEG XL 圖片格式支援，通常比 WebP、JPEG、PNG、GIF 有更好的壓縮，並設計為可取代這些格式。可在設定的 Firefox Labs 面板啟用。

  • 修正

    修正在 Squarespace、LinkedIn、eBay 等網站編輯內容時，右鍵選單可能缺少「貼上」選項的問題。

  • 修正

    改善 macOS 上將圖片從 Firefox 拖曳到桌面或 Finder：圖片現在會可靠儲存，並落到你放開的位置。

  • 修正

    在多螢幕環境中，「關於 Firefox」視窗現在更可靠地開啟在最近使用 Firefox 視窗的顯示器上。

  • 修正

    修正 macOS 與 Linux 上，在由右至左文字中方向鍵文字導覽與單字選取指令移動方向錯誤的問題。

  • 修正

    多項安全性修正。

  • 變更

    透過鍵盤或滑鼠縮放網站時，現在提供更多縮放等級，且級距更小。

  • 變更

    當 Firefox 直接開啟的 PDF 或其他檔案下載完成時，若你已切換分頁或關閉原始頁面，現在會在背景分頁開啟。

  • 變更

    側邊欄「來自其他裝置的分頁」面板現在可從右鍵選單以新分頁或新容器分頁開啟分頁。

  • 企業版

    你可以在 Firefox 152 企業版版本資訊 中找到政策更新與企業版相關的錯誤修復資訊。

  • 開發功能

    Firefox 152 開發者資訊

  • 開發功能

    開發者工具的設定面板新增選項，可切換是否在檢測器中顯示註解節點。

  • 網路平台

    Web Notifications 現在可透過 actions 選項加入操作按鈕，會顯示在通知文字下方，或在 macOS 的 Options 列表中。

  • 網路平台

    field-sizing 屬性現已可用，讓表單控制項可依內容調整大小。

  • 網路平台

    Firefox 現在支援 WebAuthn Related Origin Request 功能，讓 Passkey 可跨多個網域使用，簡化登入流程。

  • 網路平台

    Pointer Lock API 現在支援 unadjustedMovement 選項，讓網站可取得不受作業系統加速影響的原始滑鼠移動資料。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
