Firefox 新鮮事

  • 全新功能

    分割畫面變得更好用了：現在可在任何連結上按右鍵，選擇「用分割畫面開啟鏈結」，將連結與目前分頁並排開啟。建立分割畫面時也可搜尋已開啟分頁，並可透過分頁右鍵選單中的「反轉分頁順序」快速交換兩側位置。

  • 全新功能

    現在可一次分享多個分頁。選取多個分頁後按右鍵，（在 Windows 與 Linux）選擇「複製 X 個鏈結」，（在 macOS）選擇「分享」→「複製 X 個鏈結」。貼到支援 rich text 的應用程式時，會同時包含頁面標題與網址，方便閱讀。

  • 全新功能

    現在可使用 Firefox 內建的 PDF 編輯器重新排序、複製、貼上、刪除與匯出 PDF 頁面。

  • 全新功能

    在 Firefox 桌面版試用即時、隱私的翻譯功能：開啟 about:translations 頁面，或在網址列輸入「translate」並點擊快速動作捷徑前往。

  • 全新功能

    Linux 現在支援 GTK emoji picker，使用者可透過系統快捷鍵（通常是 Ctrl+.）插入 emoji。

  • 全新功能

    透過 Microsoft Store 安裝 Firefox 的 Windows 使用者，現在也可以使用 Firefox Web Apps。

  • 全新功能

    新的 Firefox 設定檔 管理系統現在開放給包含 Windows 10 的所有使用者。

  • 全新功能

    將設定檔備份到檔案現在開放給所有 Windows 10 與 Windows 11 使用者，包含使用新版設定檔管理系統的使用者。

  • 全新功能

    Firefox 現在為 Red Hat、Fedora、openSUSE 與其他 RPM-based Linux 發行版使用者提供新的 .rpm 套件。

  • 全新功能

    當網站要求使用你的位置，但 Windows 設定尚未允許 Firefox 存取位置時，Firefox 現在會提示你到 Windows 設定啟用位置存取。此行為先前只限部分 Windows 11 版本，現在適用於所有受支援的 Windows 版本。

  • 全新功能

    內建 VPN 現在開放給加拿大使用者。注意：企業版環境不包含此功能。

    目前提供地區：加拿大、法國、德國、英國、美國。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 修正

    修正 macOS 啟用封閉模式（Lockdown mode）時，網頁內容中的 emoji 字元無法顯示的問題。

  • 修正

    多項安全性修正。

  • 變更

    如果你偏好從右鍵選單建立分頁群組，現在可在「設定」→「分頁」中關閉「將分頁拖曳到一起，即可建立分頁群組」。

  • 企業版

    你可以在 Firefox 150 企業版版本資訊 中找到政策更新與企業版相關的錯誤修復資訊。

  • 開發功能

    Firefox 150 開發者資訊

  • 開發功能

    pseudo-class 切換面板新增「特定元素」區塊，包含只會對具有 open 狀態元素（例如 <dialog>）顯示的 :open pseudo-class。既有的 :visited 也移入此區塊，因為它只適用於 <a> 與 <area> 元素。（深入了解）

  • 開發功能

    Document.caretPositionFromPoint() 現在只有在新加入的 shadowRoots 選項傳入對應 ShadowRoot 時，才會回傳 shadow DOM 內的位置。

  • 開發功能

    開發者工具的網路監控器，現在會標示使用非 Mozilla Root CA Program 內憑證機構簽發憑證的連線。

  • 網路平台

    Firefox 現在支援 ariaNotify API，可用更直覺且可靠的方式發送無障礙通知（例如給螢幕閱讀器），作為 ARIA live regions 的替代方案。

  • 網路平台

    Firefox 現在支援媒體元件的 pseudo-classes（例如 :playing、:paused），讓網站可依媒體播放狀態設定更精準的樣式。

  • 網路平台

    新增 highlightsFromPoint() API 支援，可回傳指定位置上的所有 CSS Highlights，讓網頁與 CSS Highlights 互動。

  • 網路平台

    Firefox 現在支援將 light-dark() 用於圖片，就像用於色彩一樣，對網站支援暗色模式很有幫助。

  • 網路平台

    color-mix() 函式先前只接受兩個色彩值；此限制已移除，現在可接受任意數量的色彩。

  • 網路平台

    lazy-loaded 圖片元件若透過 srcset 定義多張圖片，sizes 屬性現在支援新的 auto 值，讓瀏覽器能依圖片元素的版面寬度自動選擇合適圖片。（深入了解）

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 149.0 版本更新資訊。

下載與安裝

系統需求

在安裝 Firefox 前請先確定您的電腦是否合乎系統需求。

下載 Firefox

您可以由此下載最新的 Firefox，或取得 Windows、Linux 及 Mac OS X 平台上的各國語言版本，或由此下載 Firefox 未來發行版本（測試版）。若需自行編譯其他平台或語言的版本，請見本文件最末節。

安裝 Firefox

請注意：安裝新版 Firefox 將覆蓋現存的 Firefox 程式，您不會遺失書籤或瀏覽記錄，但有些附加元件可能要更新才能繼續使用。詳細安裝步驟請參見如何安裝與更新 Firefox。

移除 Firefox

在 Windows 作業系統中，您可以使用「新增或移除程式」移除 Firefox。macOS 的使用者請將 Firefox 程式移至垃圾筒；Linux 使用者則請移除包含 Firefox 的資料夾。

一般狀況下，移除 Firefox 時不會把書籤、瀏覽記錄、擴充套件和其他附加元件一併刪除，這些資料會保留在您的「個人設定資料夾」內，此資料夾可以在「說明」選單的「更多疑難排解資訊」找到，按下「應用程式一般資訊」中「設定檔目錄」旁的按鈕便可開啟它。

請留意，若您沒有手動刪除個人設定資料夾，移除後重新安裝 Firefox 將繼續沿用原本的設定檔。

附加元件及佈景主題

您可以由「附加元件管理員」或附加元件網站取得附加元件及佈景主題。 當 Firefox 升級時，附加元件可能因不相容於新版 Firefox 而被停用，此時則需要原作者進行升級。

疑難排解

  • 設計不良或不相容的套件將導致瀏覽器發生問題，包含當機或網頁瀏覽速度變慢等等狀況。如果您碰上瀏覽器無法開啟、視窗顯示不正常等等狀況，便可能是擴充套件或佈景主題的問題。這時請參考「Firefox 輔助說明：安全模式」一文開啟 Firefox 安全模式。在安全模式下，所有附加元件及佈景主題將被停用。請您在安全模式下移除有問題的擴充套件或佈景主題，再正常地啟動瀏覽器。
  • 如果您遇到與書籤、下載、視窗位置、工具列、瀏覽記錄或其他奇怪問題，建議您在回報問題前先建立新的使用者設定檔試試。請參考「Firefox 輔助說明：使用設定檔管理員建立或移除 Firefox 設定檔」一文建立新的使用者設定檔，並將各種設定（書籤、儲存的密碼等）從舊的設定檔中分次轉移到新的設定檔（可透過 Firefox Sync 同步功能進行）。

常見問題集

  1. 我該怎麼幫忙呢？

    我們需要開發員和測試社群回饋建議，幫我們將 Firefox 變得更盡善盡美。請先查閱 Firefox 輔助說明看看有沒有相關解答，再到 Bugzilla 回報你發現的錯誤；您也可以使用意見回饋功能表達意見。

  2. 我如何預覽未來的 Firefox 版本？

    加入 Aurora 或 Beta 開發頻道就可以搶先試用 Firefox 開發中版本。

  3. 我該到哪裡才能用中文問問題跟表示意見？

    請使用 Firefox 討論區，MozTW 社群團隊與熱心的 Firefox 用戶會定期閱讀上面的文章。

  4. 我該去哪裡取得新的佈景主題與擴充功能 (附加元件)？

    請到 Mozilla 附加元件中心下載 Firefox 的擴充套件及佈景主題。

  5. Firefox 是哪些人做出來的？

    Firefox 是由世界各地的 Mozilla 社群成員與員工合力開發。這裡有份長長的名單，列出部分曾對 Firefox 有重要貢獻的人。想要加入我們的大家庭嗎？或者加入 Mozilla 台灣社群？

  6. Firefox 的原始碼在何處？

    請參照 Getting Mozilla Source Code Using Mercurial 一文取得 Firefox 原始碼；如需編譯 Firefox，請參考 Build Instructions。

  7. 電子郵件程式呢？

    Firefox 能與您預設的任何郵件程式協同運作，而我們推薦您試試我們下一代的郵件軟體：與 Firefox 合作無間的 Mozilla Thunderbird。
