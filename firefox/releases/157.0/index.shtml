Firefox 新鮮事

  • 全新功能

    Firefox 多年來最大幅度的外觀更新正式登場，透過更新後的設計系統，為瀏覽器工具列、側邊欄、選單與各項功能帶來更現代的外觀。另外也包含：

    • 全新內建佈景主題，同時提供亮色與暗色版本，一鍵即可打造個人化的 Firefox 外觀。
    • 全新精簡模式，縮小工具列與分頁間距，為網頁內容保留更多空間，尤其適合小螢幕與分割畫面配置。

  • 全新功能

    WebRTC 視訊通話現在可在支援的裝置上使用 AV1 硬體解碼，不再一律以軟體解碼 AV1 影片。

  • 全新功能

    當 Firefox 設定為記錄加密金鑰時，現在會在網站資訊面板（網址列上的盾牌圖示）與設定中顯示警告，因為這可能讓電腦上的其他軟體讀取加密的網路流量。

  • 全新功能

    Firefox Suggest 現在於奧地利、比利時、捷克、丹麥、芬蘭、匈牙利、愛爾蘭、盧森堡、荷蘭、挪威、波蘭、葡萄牙、斯洛伐克、西班牙、瑞典與瑞士的網址列提供建議。你可以在 Firefox Suggest 設定中管理這些建議。（深入瞭解）

  • 修正

    修正手機與平板電腦的影像在 WebRTC 通話中橫轉或上下顛倒的問題。

  • 修正

    修正頁面仍在載入時（例如 Firefox 剛啟動後不久），網址列搜尋輸入的文字，而非開啟已選取建議的問題。

  • 修正

    修正 Windows 上部分以 8 位元色彩格式編碼的 HDR 影片，畫面黯淡灰白，未以 HDR 顯示的問題。

  • 修正

    改善反覆變更影片播放速度時的影音同步，例如在 YouTube 上調整播放速度。

  • 修正

    修正全螢幕模式下將游標移至螢幕邊緣時，垂直分頁側邊欄未重新顯示的問題。

  • 修正

    修正 Windows 上影片切換為全螢幕後，工作列仍顯示在影片上方的問題。

  • 修正

    多項安全性修正。

  • 變更

    按下 Tab 鍵，焦點現在會直接移至網址列與搜尋列的文字欄位，不再先停留在搜尋引擎按鈕上。仍可使用 Shift+Tab 將焦點移至該按鈕。

  • 變更

    Amazon 不再列為內建搜尋引擎。你仍可在搜尋設定中，將它加入為自訂搜尋引擎。（深入瞭解）

  • 變更

    更新後的側邊欄現在已為所有使用者啟用。原本仍使用舊版側邊欄的使用者，將保留類似的配置，面板切換器位於側邊欄頂端。此外，設定中的「顯示側邊欄」選項已移除。

    我們持續改善新設計的同時，你仍可在 about:config 中將 sidebar.revamp 設為 false，還原舊版側邊欄，但這也會關閉垂直分頁。此偏好設定將保留至 2027 年底。

  • 變更

    網頁的 alert()、confirm() 與 prompt() 對話框、色彩與日期選擇器，以及表單自動完成下拉選單，現在會配合網頁的亮色或暗色配色。

  • 企業版

    你可以在 Firefox 157 企業版版本資訊 中找到政策更新與企業版相關的錯誤修正資訊。

  • 開發功能

    Firefox 157 開發者資訊

  • 網路平台

    Firefox 現在支援在 @supports 中使用 at-rule() 函式，讓開發者能偵測瀏覽器是否支援特定 at-rule，例如 @supports at-rule(@scope)。

  • 網路平台

    Firefox 現在支援 CSS overscroll-behavior 屬性的 chain 值。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
