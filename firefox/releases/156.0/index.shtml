Firefox 新鮮事

  • 全新功能

    macOS 上的 Firefox 現在可在設定的「啟動」區段中，設為在電腦開機時自動開啟。

  • 全新功能

    法國、德國與義大利的網址列現在提供在地化的維基百科建議，以及偶爾出現的贊助建議。你可在 Firefox Suggest 設定中關閉這些建議。

  • 修正

    修正在富文字編輯器中將圖片拖曳至新位置時，圖片可能被一長串文字取代，而非移動的問題。

  • 修正

    修正 Bilibili 等網站無法播放 MP4 中高取樣率 FLAC 音訊的問題。

  • 修正

    修正開啟子母畫面視窗後，才在影片播放器中啟用字幕時，字幕未顯示於子母畫面視窗的問題。

  • 修正

    修正在書籤側邊欄中同時選取並拖曳資料夾及其內部書籤時，書籤移出原資料夾的問題。

  • 修正

    修正反轉分割檢視的左右面板後，分頁中的尋找列持續無法使用的問題。

  • 修正

    修正啟用 DNS over HTTPS 後，部分不支援 HTTPS 的網站無法載入的問題。

  • 修正

    修正部分使用者啟用內建 VPN 後，Firefox 完全無法連線至網路的問題。

  • 修正

    修正 Windows 上 Firefox 可能阻止自動隱藏的工作列顯示的問題。

  • 修正

    多項安全性修正。

  • 變更

    Firefox 內建 PDF 檢視器的啟動速度，現在最高可提升 45%。

  • 變更

    改善 Firefox 將大型 JPEG 圖片縮小至符合頁面大小時的記憶體與 CPU 使用量。

  • 變更

    搭載 ARM64 處理器的 Windows 裝置，現在進行 WebRTC 視訊通話時可使用 H264 硬體解碼，不必再退回軟體解碼。

  • 企業版

    你可以在 Firefox 156 企業版版本資訊 中找到政策更新與企業版相關的錯誤修正資訊。

  • 開發功能

    Firefox 156 開發者資訊

  • 網路平台

    text-box-trim 現在會在適用時採用 ::first-line 偽元素的字型度量，與其他瀏覽器及規格保持一致。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
