Firefox 新鮮事

  • 全新功能

    Firefox 的區域網路存取保護現在也套用至 WebSocket 連線。嘗試透過 WebSocket 連線到區域網路裝置的網站，現在必須先取得權限。

  • 全新功能

    在智慧視窗中，Firefox 現在可以建議相關分頁群組，並為每個群組提出名稱。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 全新功能

    Windows 上的 Firefox 現已支援 NVIDIA GeForce NOW，可直接在瀏覽器中串流支援的 PC 遊戲。

  • 全新功能

    除了 Windows 和 Linux 之外，macOS 現在也提供 Firefox 本機設定檔備份功能，且備份可以在這三個平台之間進行還原。

  • 全新功能

    現在可以將網站排除在「關閉時清除 Cookie 和網站資料」之外，而無需同時將其排除在追蹤保護和其他 Cookie 限制之外。

  • 全新功能

    全頁翻譯功能現在也會翻譯 <iframe> 內容。

  • 全新功能

    全頁翻譯功能現在於所有頁面載入時均會執行語言辨識，從而為使用者提供更好的翻譯建議體驗。

  • 全新功能

    Windows 使用者現在可以在設定中選擇不同的 Firefox 應用程式圖示。MSIX 安裝、macOS 與 Linux 目前尚不支援，但很快就會加入了。

  • 全新功能

    網址列現在包含「管理 AI」快速動作，可開啟設定中的 AI 控制。

  • 全新功能

    對頁面進行強制重新整理（在按住 Shift 鍵的同時點擊重新整理按鈕）現在也會清除並更新其快取的網站圖示（favicons）。

  • 修正

    修復了 macOS 上的一個問題：關閉瀏覽器視窗後可能會留下一個不可見的視窗，並持續在原先區域擷取滑鼠點擊。

  • 修正

    修復了 Windows 上的一個問題：在啟動後，自動隱藏的工作列直到 Firefox 視窗最小化並恢復後才會出現。

  • 修正

    修復了 Windows 工作列會出現在全螢幕子母畫面視窗前方的問題。

  • 修正

    修復了垂直分頁側邊欄在全螢幕模式下保持可見的問題。現在它會隨工具列一起隱藏，並在游標移至螢幕邊緣時重新出現。

  • 修正

    修復了在使用「配合頁面寬度」選項時，PDF 文件在列印預覽中未能正確縮放的問題。

  • 修正

    多項安全性修正。

  • 變更

    影片播放位置的跳轉速度在所有作業系統上都已顯著提升，能更快跳到影片中的特定位置。

  • 變更

    PDF 中選取的文字現在會以與網頁文字相同的方式醒目提示，且醒目提示顏色會遵循作業系統設定（例如高對比模式）。

  • 變更

    對於新設定檔以及最近未使用 Firefox View 的設定檔，Firefox View 預設將移出工具列。你仍可透過「列出所有分頁」>「檢視所有分頁」來開啟它，或透過「自訂工具列」選單將其加回。

  • 企業版

    你可以在 Firefox 154 企業版版本資訊 中找到政策更新與企業版相關的錯誤修復資訊。

  • 開發功能

    Firefox 154 開發者資訊

  • 開發功能

    JSON 檢視器現在會在底部顯示所選項目的麵包屑路徑。

  • 網路平台

    Firefox 現在支援 text-box-trim 與 text-box-edge CSS 屬性，以及相關的 text-box 簡寫屬性。這些屬性可控制文字上下的前導空白，讓垂直間距與對齊更簡單且一致。

  • 網路平台

    Firefox 現在支援 sibling-index() 與 sibling-count() CSS 函式。這些函式可利用元素在兄弟元素中的索引，以及兄弟元素的總數（包括該元素本身）進行計算，並據此設定元素樣式。

  • 網路平台

    <input type="time"> 與 <input type="datetime-local"> 新增時間選擇器介面，讓選取時間更無障礙且更直覺。

  • 網路平台

    新增對 HTTP 磁碟快取之 No-Vary-Search HTTP 回應標頭的支援。現在伺服器可以宣告哪些 URL 查詢參數與回應無關，讓 Firefox 能夠在不同參數變化間重複使用快取資源，進而提高快取命中率。

  • 網路平台

    Firefox 現在支援新的 Iterator.prototype.chunks 與 Iterator.prototype.windows 方法，允許將迭代器取用為可配置大小的重疊或非重疊子序列。

  • 網路平台

    Firefox 現在支援 Iterator.prototype.includes()，讓開發者可以直接檢查迭代器是否包含特定值，而無需先將其轉換為陣列。

  • 網路平台

    Firefox 現在支援 Iterator.prototype.join 方法，該方法允許將迭代器連接成一個字串，類似於 Array.prototype.join。

已知問題

  • 尚待修復

    Firefox 最近調整地址自動填寫的處理邏輯後，部分使用者在自動填寫地址時可能失敗。（Bug 2065145）已於 Firefox 154.0.1 修復。

  • 尚待修復

    Firefox 最近調整密碼儲存機制後，部分使用者在 Firefox 存取已儲存的密碼時可能遇到效能變慢。啟用主要密碼的使用者也可能在啟動 Firefox 或開啟特定內容時，意外看到密碼提示。（Bug 2064411）已於 Firefox 154.0.1 修復。

  • 尚待修復

    啟用垂直分頁的使用者，側邊欄可能在 Firefox 重新啟動後無法維持顯示。重新啟動後，可點擊側邊欄工具列按鈕再次啟動垂直分頁。修正正在開發中。（Bug 2065431）

  • 尚待修復

    在全螢幕模式下隱藏工具列時（Windows 與 Linux 的預設行為），將游標移至螢幕左緣時，垂直分頁側邊欄不會出現。暫時解法：將游標移至螢幕頂端，以同時顯示工具列與側邊欄；或者右鍵點擊工具列，取消勾選「隱藏工具列」。我們正在修復中。（Bug 2064638）

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
