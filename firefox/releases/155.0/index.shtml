Firefox 新鮮事

  • 全新功能

    智慧視窗現在開放美國、加拿大與法國的所有使用者試用！Firefox 155 也帶來多項改善：

    • 新增個人化的對話續聊提示，協助使用者快速回到先前處理的主題。

    • 助理現在透過 Exa 網頁搜尋提供來源引用，回應速度大幅提升，僅需原先約五分之一的時間，就能以準確、可信的網路資料作為回應依據。

    • 整理分頁功能現在能更妥善地將相關分頁分組，並為每個群組提供更清楚、更具描述性的名稱。

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 全新功能

    Firefox 現在會在網址列顯示已封鎖的追蹤器數量，讓你在瀏覽時更容易看見內建隱私保護的成效。你可以在設定中隱藏數量，同時繼續封鎖追蹤器。

  • 全新功能

    Nintendo Switch Pro 與相容的第三方控制器現在可在 Windows 網頁遊戲中完整運作，方向鍵與類比搖桿的按鍵對應也已修正。

  • 全新功能

    現在可在設定中調整容器的排列順序，所有列出容器的地方都會採用這個順序。

  • 全新功能

    翻譯功能現在支援下列語言：

    • 馬拉地語
    • 烏爾都語
  • 修正

    修正 Linux 上使用特定鍵盤配置輸入文字時，Microsoft 365 Word Online 與其他網頁應用程式中的文字消失的問題。

  • 修正

    修正在 Google 文件使用鍵盤快捷鍵貼上純文字時，出現不必要的貼上確認提示。

  • 修正

    當作業系統未能結束分頁拖曳操作，導致工具列與分頁列無回應時，Firefox 現在可以恢復正常運作。

  • 修正

    修正按鈕內的文字無法選取或複製，導致無法複製 X 私訊與 YouTube 留言的問題。

  • 修正

    修正網路廣播等即時音訊串流在背景播放時停止的問題。

  • 修正

    修正分頁移至另一個視窗後，音效指示圖示消失，導致無法辨識或靜音正在播放內容的分頁。

  • 修正

    修正長時間瀏覽後，Firefox 阻止 Linux 系統進入睡眠的問題。

  • 修正

    修正配備相機瀏海的 MacBook 顯示全螢幕內容時，畫面出現上下黑邊的問題，尤其是在觀看影片時。

  • 修正

    修正部分嵌入其他網站內容的網頁，無法使用方向鍵與 Page Up／Page Down 捲動的問題。

  • 修正

    修正 Windows 上網頁中的部分較少見文字顯示為空方框的問題。

  • 修正

    修正 macOS 上 WebCodecs VideoEncoder 編碼 NV12 格式的 VideoFrame 時停滯的問題。

  • 修正

    多項安全性修正。

  • 變更

    Firefox 現在將 CSS 區塊與函式的巢狀深度限制為 75 層，以防止過深的巢狀結構在特定情況下造成當機。超過此深度的規則與值將不再解析。

  • 變更

    Firefox 現在改用 firefox-portal-detection.com 偵測網路登入頁面與檢查網路連線，取代 detectportal.firefox.com。網路允許清單若使用舊網域，需同步更新。

  • 變更

    Firefox 現在只會在使用者明確操作後開啟 mailto: 連結，網頁無法再未經使用者操作就啟動預設郵件程式。

  • 變更

    列印時，現在可將縮放比例設為超過 100%，把小於紙張尺寸的 PDF 放大至填滿紙張。

  • 企業版

    你可以在 Firefox 155 企業版版本資訊 中找到政策更新與企業版相關的錯誤修正資訊。

  • 開發功能

    Firefox 155 開發者資訊

  • 開發功能

    規則檢視器現在提供模擬 prefers-reduced-motion 媒體特性的切換選項。模擬選項也已移至點擊 at-rule（@）按鈕後開啟的新面板中。

  • 開發功能

    開發者工具的除錯器現在可使用鍵盤快捷鍵 Ctrl+Alt+B（macOS 為 Cmd+Alt+B），一次啟用或停用所有中斷點。

  • 開發功能

    JSON 檢視器現在可顯示 JSON Lines（JSONL／NDJSON）文件，並在無效的行內顯示錯誤。

  • 開發功能

    修正儲存空間面板將隱私視窗、容器與其他分割區的 Cookie，和受檢查頁面本身的 Cookie 混在一起顯示的問題。

  • 開發功能

    未捕捉的非 Error 例外，現在會在主控台列出屬性名稱，而非只顯示 Object。

  • 網路平台

    CSS attr() 函式現在支援任意型別的值，讓開發者能在任何屬性中使用元素屬性值，不再侷限於在 content 屬性中以字串形式使用。

  • 網路平台

    Firefox 現在支援 progress() CSS 函式。

  • 網路平台

    Firefox 現在支援 alpha() CSS 函式。這是一個相對色彩函式，可單獨修改指定色彩的 alpha 分量。

  • 網路平台

    Firefox 現在支援 await dictionary 提案中的 Promise.allKeyed 與 Promise.allSettledKeyed 方法。這些方法接受以 Promise 為屬性值的物件，並回傳一個 Promise；成功完成時，結果物件會沿用輸入物件的鍵名。

  • 網路平台

    Firefox 現在支援 WebAssembly Compact Import Section 提案，可縮小包含大量匯入項目的 WebAssembly 模組。

  • 網路平台

    Firefox 現在支援 WebAssembly Wide Arithmetic 提案，新增 128 位元算術指令，改善密碼學與任意精確度數學運算的效能。

  • 網路平台

    Firefox 現在支援在 HTTP/3 連線中使用 QUIC 第 2 版（RFC 9369）。當伺服器透過相容版本協商（RFC 9368）選用此版本時，Firefox 就會使用它。

  • 網路平台

    Firefox 153 加入的非標準 ::-webkit-scrollbar 偽元素支援，現在僅套用至少數特定網站，不再全面啟用。

  • 網路平台

    SVG <a> 元素現在提供與 HTML 連結相同的 URL 屬性，包含 protocol、host、pathname 與 search。

  • 網路平台

    SVGGraphicsElement.getBBox() 現在會遵循 options 引數，讓邊界框可納入描邊、標記與裁切的影響。

  • 網路平台

    現在支援使用 font-width 屬性，作為 font-stretch 的標準名稱。

  • 網路平台

    動態 import() 若因網路或 HTTP 錯誤失敗，不再於模組對應表中快取為失敗，因此重試相同的模組指定字串時，現在可以成功載入。

  • 網路平台

    WebTransport 現在支援傳送群組（createSendGroup()），以控制串流間的頻寬分配；也支援可寫入的資料報串流（createWritable()），以及用來衍生與 TLS 工作階段綁定金鑰的 exportKeyingMaterial()。另新增 draining Promise 與子協定協商支援，可透過建構子的 protocols 選項提供候選子協定，並由 protocol 屬性取得協商結果。

  • 網路平台

    Firefox 現在支援以 RTCError 回報資料通道失敗、RTCSctpTransport.maxChannels、雙位元組 RTP 標頭擴充識別碼，以及更精確的 RTCTransportStats，改善 WebRTC 互通性。

已知問題

  • 尚待修復

    啟用垂直分頁的使用者重新啟動 Firefox 後，側邊欄可能不再顯示。重新啟動後可點擊工具列上的側邊欄按鈕，重新啟用垂直分頁。已於 Firefox 155.0.1 修復。

  • 尚待修復

    在封鎖 UDP 的網路中，部分網站可能載入緩慢或無法載入，例如 Proxy 或防火牆在 TLS 檢查過程中封鎖 QUIC 的企業網路。暫時可透過 Preferences 原則將 network.http.happy_eyeballs_enabled 設為 false。已於 Firefox 155.0.1 修復。（Bug 2063452）

  • 尚待修復

    macOS 上部分格式的標準動態範圍（SDR）影片，色彩可能顯得泛白。此問題正在調查中，將於未來版本修正。（Bug 2068961）
