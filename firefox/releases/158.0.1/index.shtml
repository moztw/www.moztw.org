Firefox 新鮮事

  • 修正

    Mozilla 已於 10 月 17 日透過 OneCRL 封鎖私密金鑰遭洩漏的 eMudhra 中繼憑證，並在同一天透過 Remote Settings 將封鎖資訊傳送至用戶端。此更新內含最新的 OneCRL 封鎖清單，確保即使 Remote Settings 被原則停用，或因使用者的網路環境而無法使用，用戶端仍會封鎖這些受影響的憑證。（深入瞭解）

  • 修正

    修正選取文字時，頁面非預期捲回頂端的問題。（Bug 2081016）

  • 修正

    修正 Windows 上執行螢幕閱讀器或其他輔助技術時，列印網頁或將網頁儲存為 PDF 可能發生當機的問題。（Bug 2082376）

  • 修正

    修正 Linux 多螢幕配置下，Firefox 在錯誤螢幕上開啟視窗的問題。（Bug 2076558）

  • 修正

    修正部分使用者無法啟用內建 VPN 的問題。（Bug 2055094）

  • 修正

    修正 macOS 上從其他應用程式拖曳檔案至 Firefox 時，檔案未放置到網頁上的問題。（Bug 2078954）

  • 修正

    多項安全性修正。

  • 請參考此版本的完整變更清單。 你可能也想瞭解 Firefox 版本更新資訊。
