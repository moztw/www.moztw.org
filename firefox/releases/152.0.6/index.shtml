Firefox 新鮮事

  • 全新功能

    Smart Window 包含多項改進：

    • 在頁面上選取文字後，可快速透過內建助手進行摘要、說明等操作。（Bug 2034921）
    • 新分頁新增一列捷徑，方便回到常用網站。（Bug 2048338）

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 修正

    修正重新設計的 Firefox 設定中，無法停用電子郵件追蹤保護的問題。（Bug 2049331）

  • 修正

    修正 macOS 26 上使用檔案選擇對話框後可能發生的掛起。（Bug 2053177）

  • 修正

    修正部分使用舊版 autoconfig 格式設定首頁的企業組態下，首頁無法載入的問題。（Bug 2047962）

  • 修正

    多項安全性修正。
