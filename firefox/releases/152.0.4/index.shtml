Firefox 新鮮事

  • 全新功能

    Smart Window 包含多項改進：

    • 現在可請它關閉分頁；必要時會要求確認，之後也可復原。（Bug 2040769）
    • 瀏覽記錄結果現在會顯示圖片。（Bug 2038069）
    • 對回應提供回饋時，現在可選擇常見原因，並在送出前預覽將分享的內容。（Bug 2033002）

    某些新的 Firefox 功能採行逐步釋出（progressive roll out），意味著某些使用者會比其他人更早看到此功能。如此有助於獲取早期回饋，迅速發現錯誤與改善行為，從而提升整體 Firefox 使用者的體驗。

  • 修正

    修正 macOS 系統對話框（例如儲存與開啟面板）內，複製、貼上、復原、重做等鍵盤快捷鍵無法使用的問題。（Bug 2040851、Bug 2040844）

  • 修正

    修正從設定搜尋結果開啟「管理 Cookie 與網站資料」對話框時，清單為空白的問題。（Bug 2041077）

  • 修正

    修正跟隨頁面內連結後鍵盤焦點落在錯誤位置，導致按 Tab 無法從連結處繼續的問題。（Bug 2049307）

  • 修正

    多項安全性修正。
